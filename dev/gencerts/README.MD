# gencerts

Утилита для генерации и сохранения сертификатов в формате .pem.

## Описание

Генерирует RSA-ключ 4096 бит и X.509 сертификат для использования в криптографической подписи и шифровании метрик и сохраняет в директорию `.certs` в корне проекта.

## Сгенерированные файлы

- `.certs/cert.pem` - публичный сертификат (X.509), используется агентом (`-crypto-key cert.pem`)
- `.certs/private.pem` - приватный ключ (RSA, PKCS1), используется сервером (`-crypto-key private.pem`)

## Сценарии запуска

```bash
# Из корня проекта
go run ./dev/gencerts/main.go

# Из директории gencerts
go run ./main.go
```
